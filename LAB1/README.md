Nội dung 
1. Thiết lập mô hình mạng Client và Server.

3. Dùng Wireshark bắt và phân tích gói tin Telnet.

5. So sánh mức độ bảo mật giữa Telnet và SSH.
 Kết quả

1. Kiểm tra kết nối Client - Server: PASS (mẫu).
2. Kết nối Telnet: PASS (mẫu).
3. Bắt gói tin Telnet: PASS (mẫu).
4. Kết nối SSH: PASS (mẫu).
5. Bắt gói tin SSH: PASS (mẫu).

Telnet không mã hóa dữ liệu nên có thể đọc được nội dung khi bắt gói tin. SSH mã hóa dữ liệu nên an toàn hơn khi kết nối từ xa.
